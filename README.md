# E-Commerce Back-End API (Spring Boot)

This is a robust back-end application built with **Java** and **Spring Boot** to support a modern travel agency e-commerce platform. It was developed as the final project for the D288 Back-End Programming course at Western Governors University (WGU).

### 🚀 Key Features
*   **RESTful API:** Provides secure endpoints to handle customer data, vacations, excursions, and shopping cart checkout processes.
*   **Database Integration:** Utilizes Spring Data JPA and Hibernate to seamlessly map object-oriented data to a **MySQL** relational database.
*   **Data Validation:** Enforces strict backend validation rules (e.g., `@NotBlank`, `@NotNull`) to ensure data integrity before persistence.
*   **Unique Tracking:** Automatically generates secure, randomized UUIDs for order tracking numbers upon successful checkout.
*   **CORS Configuration:** Fully configured to allow cross-origin requests from the Angular front-end.

### 💻 Technology Stack
*   **Language:** Java
*   **Framework:** Spring Boot, Spring MVC
*   **Data Persistence:** Spring Data JPA, Hibernate, MySQL Driver
*   **Tools:** Lombok, Maven, IntelliJ IDEA

This project showcases my ability to bridge the gap between complex relational databases and modern front-end frameworks using the Spring ecosystem.
